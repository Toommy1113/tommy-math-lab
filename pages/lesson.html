02

拆解思路

1

判定为 0/0 型未定式

x → 1 时，分子与分母均趋于零，不能直接应用商的极限运算法则。需进一步比较分子与分母的趋零速度。

2

通过有理化提取共同因子 x − 1

分母分解为 (x − 1)(x + 1)，其中 x − 1 是趋零因子。分子为平方根之差，可利用共轭式将其转化为被开方数之差：

(3−x)−(1+x)=−2(x−1)

被开方数之差恰含因子 x − 1，这是本题选择有理化的依据；仅有“含根式”这一特征不足以确定最合适的方法。

3

约去趋零因子，再应用极限运算法则

在 0 < |x − 1| < 1 内，两根式及共轭式均为正，且 x − 1 ≠ 0，故变形与约分合法。化简后分母趋于 4√2 ≠ 0，可应用商的极限法则。

优先方法：有理化

将平方根差转化为被开方数之差，可直接得到共同因子 x−1。该路线使用恒等变形与极限运算法则，不需要额外的渐近展开。

03完整解答展开步骤⌄
教学总分 8 分

① 乘共轭式

——————3分

设所求极限为 L。在 0 < |x − 1| < 1 内，分子、分母同乘非零共轭式 √(3−x) + √(1+x)，得

L=limx→1(3−x)−(1+x)(x2−1)(3−x+1+x)

② 分解并约去共同因子

——————3分

在 x = 1 的充分小去心邻域内，x − 1 ≠ 0，可约去该共同因子。

L=limx→1−2(x−1)(x−1)(x+1)(3−x+1+x)
=limx→1−2(x+1)(3−x+1+x)
函数在某点的极限由其去心邻域内的取值决定，不要求函数在该点有定义。

③ 对化简后的式子求极限

——————2分

化简后的分母趋于 4√2 ≠ 0，由连续性和商的极限法则，

L=−22(2+2)=−24
最终结果−24

这里的分值为教学建议，实际考试以老师的评分标准为准。

04

易错提醒

误将 0/0 型未定式判为 1⌄

分子与分母同时趋于零，并不能确定商的极限。例如 x → 0 时，x/x → 1，而 x²/x → 0，说明还需比较二者的相对趋零阶。

将根式替换为其极限值，丢失增量信息⌄

由极限的减法法则，可以判断分子趋于零；但这不足以计算原商的极限。若将两个根式直接替换为 √2，便丢失了分子的一阶增量。它们的增量之差为 −(√2/2)(x−1) + o(x−1)，不能当作恒等于零。

混淆趋近点与去心邻域的运算条件⌄

本题的约分是在 x = 1 的去心邻域内进行的。原式与化简式在该范围内恒等，因此二者在 x → 1 时具有相同的极限。
