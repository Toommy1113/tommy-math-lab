无穷减无穷的转化

基础
01 读题与识别 / 第09题 · 求极限第一章方法可解

求极限：

limx → +∞x² + x − x
知识点
02

拆解思路

1

两个量都变大，先观察相减后剩下多少

题型判断：∞−∞ 型未定式 · 根式差。

x→+∞ 时，√(x²+x) 和 x 都趋于+∞，这是 ∞−∞ 型。我不能把两个“无穷大”直接相减；看到根号内的 x²+x，我反而想比较它与 x² 的差。两边主要部分同为 x，直接代入只会掩盖剩余量。

2

共轭式能把被开方数之差变成 x

我会试着乘以共轭式，并不是因为见到根号就一定有理化，而是因为 x→+∞ 时 x=√(x²)，有理化后恰好出现 (x²+x)−x²=x：

√(x²+x) − x = (x²+x) − x²√(x²+x) + x = x√(x²+x) + x

原来隐藏在相减里的差，现在成为分子；共同的增长尺度 x 也能从分母提出。这比单独比较两个趋于无穷的量更直接。

3

同除 x，才把无穷远处的比值变成有限极限

x√(x²+x) + x = 1√(1 + 1/x) + 1

x>0 时 √(x²+x)=x√(1+1/x)，共轭式的分母也为正，因此变形合法。新分母趋于2，不为零，商法则给出1/2。若改为 x→−∞，√(x²)=|x| 而不是 x，不能沿用这一步。

优先方法：共轭有理化，再同除 x

这里的有理化有明确目标：把根式差转成 (x²+x)−x²，再除去两边共有的增长尺度 x。仅凭“含根式”还不足以决定用它；如果有理化不能消去相减造成的不确定因素，就应重新观察结构。用展开式也可比较，但本题的恒等变形更直接。

我的解题经验总结

本题要训练的是比较两个无穷大量相减后留下的差。以后看到根式与它的主要项相减，我会先检查共轭相乘能否产生简单的被开方数之差，再注意无穷远处开平方时的绝对值。

03完整解答展开步骤⌄
教学总分 6 分

① 判断未定式和符号范围

——————2分

x→+∞ 时，√(x²+x)→+∞，x→+∞，原式为 ∞−∞ 型。取 x>1，则 x²+x>0，x>0，共轭式 √(x²+x)+x>0。

② 关键：用共轭式作恒等变形

——————3分
√(x²+x) − x = (√(x²+x) − x)(√(x²+x) + x)√(x²+x) + x = x√(x²+x) + x

因 x>0，√(x²+x)=x√(1+1/x)，故

x√(x²+x) + x = 1√(1 + 1/x) + 1

③ 由连续性和商法则求极限

——————1分
limx → +∞√(x²+x) − x = limx → +∞1√(1 + 1/x) + 1 = 12

1/x→0，根号内趋于1，分母趋于2≠0。

最终结果12

这里的分值仅为教学建议（条件与识别2分、关键变形3分、求值1分），不是原题分值；实际考试以老师的评分标准为准。

04

易错提醒

把 ∞−∞ 当作零⌄

“两个量都趋于无穷”不能决定它们的差。本题的差趋于1/2；必须先保留差并完成合法变形。

把 √(x²) 在任何方向都写成 x⌄

恒等式是 √(x²)=|x|。本题 x→+∞ 时充分大的 x 为正，才可把 |x| 写成 x；负无穷方向不能照搬。

有理化后直接认为 x 趋于无穷，分母也趋于无穷，结果为1⌄

分子、分母仍是 ∞/∞ 型，不能只看它们同趋无穷。须同除 x，比较分母中 √(x²+x)/x 与 1 的极限。
