复合函数的定义域

基础
01 读题与识别 / 第01题 · 求定义域第一章方法可解

已知 f(u) 的定义域为 [0, 2]，求 F(x) 的定义域。

F(x) = f(ln x) + ln(3 − x)
知识点
02

拆解思路

1

先分清：[0,2] 限制的是谁？

题型判断：复合函数的定义域 · 多条件取交集。

看到 f(u) 的定义域是 [0,2]，我会先抓住这句话的意思：送进 f 的数必须在 0 到 2 之间。现在送进去的是 ln x，所以应限制 0≤ln x≤2，不能直接把 x 限制在 [0,2]。字母换了，外层函数对输入的要求并没有变。

2

逐层检查，让式子的每一部分都有意义

F(x) 是两项相加，两项必须同时有意义。我会分别检查：ln x 本身要求 x>0；f(ln x) 要求 0≤ln x≤2；另一项 ln(3−x) 要求 3−x>0。这样列条件，是为了避免只顾复合函数，漏掉另一项对数。

x > 0，0 ≤ ln x ≤ 2，3 − x > 0

自然对数严格递增，所以中间的条件可以化为 1≤x≤e²。它已经包含 x>0，不必重复保留；最后一个条件则给出 x<3。求和中的两项都要成立，所以这些范围应取交集。

3

最后检查端点，决定用方括号还是圆括号

[1, e²] ∩ (−∞, 3) = [1, 3)

因为 e²>3，真正限制右端点的是 x<3。再代回检查：x=1 时，ln x=0 可以送入 f，ln(3−x)=ln 2 也有意义；x=3 时却出现 ln 0，必须排除。这样我就能确认左端点取到、右端点取不到。

优先方法：逐层列条件，再取交集

题目没有给 f 的具体表达式，但求定义域只需要知道它允许哪些输入。因此我会沿着表达式逐层列条件，再取交集。这里不用猜 f 的形式，也不能先给 F(x) 的结果附加一个 [0,2] 范围；[0,2] 约束的是 f 的输入。

我的解题经验总结

这道题要训练的是把“外层函数的输入限制”转成对 x 的限制。遇到复合函数，我会先问实际送入外层的量是什么，再检查其余根号、对数、分母等条件，最后取交集并核对端点。

03完整解答展开步骤⌄
教学总分 6 分

① 列出所有有意义的条件

——————2分

F(x)=f(ln x)+ln(3−x) 有意义，当且仅当下列条件同时成立：

x > 0，ln x ∈ [0,2]，3 − x > 0

第一项既需内层对数存在，也需其值落入 f 的定义域；第二项需对数真数严格为正。

② 关键：把外层输入范围转成 x 的范围

——————3分

指数函数严格递增，由 0≤ln x≤2 得

e⁰ ≤ x ≤ e²，即 1 ≤ x ≤ e²

这已保证 x>0。同时 3−x>0 等价于 x<3。因此

D = [1,e²] ∩ (−∞,3) = [1,3)

其中 e²>3，所以交集的右端点由第二个对数决定。

③ 核对端点并写出结论

——————1分

x=1 时两项均有定义；x=3 时 ln(3−x) 无定义。因此 F 的定义域为 [1,3)。

最终结果[1, 3)

这里的分值仅为教学建议，不是原题分值；实际考试以老师的评分标准为准。

04

易错提醒

直接把 F 的定义域写成 [0,2]⌄

[0,2] 是 f 的输入 u 的范围。在 f(ln x) 中，u=ln x，所以必须解 0≤ln x≤2，不能直接把 u 的范围当成 x 的范围。

两项的范围取并集⌄

求和要求两项同时有意义，应取交集。只让其中一项有意义，另一项仍可能无定义，整个和也就无定义。

把对数条件写成真数≥0，误收进 x=3⌄

实数对数要求真数严格大于0，ln 0 不存在。因此 3−x>0，不能改成 3−x≥0。

不知道 f 的表达式，就以为无法求定义域⌄

此题已经给出了 f 的完整定义域；只需保证 ln x 落在其中。f 的具体输出是多少，不影响这一步输入条件的判断。
