反函数与奇偶性

基础
01 读题与识别 / 第02题 · 函数性质第一章方法可解

求函数的值域、反函数，并判断原函数与反函数的奇偶性。

f(x) = ln 1 + x1 − x

−1 < x < 1

知识点
02

拆解思路

1

要找反函数，先确认不同输入不会得到同一输出

题型判断：值域、反函数与奇偶性的综合判断。

题目同时问值域、反函数和奇偶性，我会先理清依赖关系：原函数的值域就是反函数的定义域，但前提是原函数在给定区间内一一对应。所以不能只把式子反解出来就结束，还要确认反函数确实存在。

这里 (1+x)/(1−x)=2/(1−x)−1。在 −1<x<1 内，x 增大时，正数 1−x 变小，它的倒数变大，所以这个比值严格增大；ln 又严格递增，f 也严格递增。这样就保证了每个函数值只对应一个 x。

2

先反解，再看哪些输出真的能取到

令 y=ln[(1+x)/(1−x)]。要从输出 y 找回输入 x，我会先取指数，把最外层的对数去掉，再把含 x 的项移到一起：

eʸ = 1 + x1 − x，x = eʸ − 1eʸ + 1

这个式子对任意实数 y 都有意义，因为 eʸ>0，分母不会为零。不过这还不够：算出的 x 还必须落在原定义域内。令 a=eʸ>0，就有 −1<(a−1)/(a+1)<1。代回后确实得到 y，所以每个实数输出都能取到，值域是 ℝ。

这一步把值域和反函数一起解决了：任意 y 都能唯一找回一个合法的 x。最后按惯例互换字母，写成 f⁻¹(x)。

3

判断奇偶性时，先看定义域，再代入 −x

原函数的定义域 (−1,1) 关于0对称，可以比较 f(−x) 和 f(x)。代入 −x 后，分式恰好变为原来的倒数；正数取倒数后，对数变号，所以 f(−x)=−f(x)。

反函数定义域是 ℝ，也关于0对称。它的式子里有 e⁻ˣ，我会把分子分母同乘 eˣ，把负指数变成正指数；整理后正好是原式的相反数。因此两者都是奇函数。

优先方法：先确认一一对应，再反解并检验

反解本来就是题目要求的一部分，而检验反解得到的 x 是否始终合法，还能直接确定原函数的值域，因此我会合并处理这两个问题。奇偶性则用定义核查。求导也能证明单调，但这里用正数的大小关系就足够，无需引入后续工具。

我的解题经验总结

这道题要把定义域、值域和反函数的对应关系连起来。以后求反函数，我会先确认一一对应，反解后核对变量的范围；判断奇偶性时，先检查定义域是否对称，再比较代入 −x 后的表达式。

03完整解答展开步骤⌄
教学总分 8 分

① 确认原函数在 (−1,1) 上严格递增

——————2分

在给定区间内，1+x>0、1−x>0，对数有定义。若 −1<x₁<x₂<1，则

0 < 1−x₂ < 1−x₁
21−x₁ − 1 < 21−x₂ − 1

即 (1+x₁)/(1−x₁)<(1+x₂)/(1−x₂)。由于 ln 严格递增，f(x₁)<f(x₂)，故 f 是一一对应的，存在定义在其值域上的反函数。

② 关键：反解并核对值域与反函数的定义域

——————4分

设 y=f(x)，取指数并整理：

eʸ(1−x)=1+x，(eʸ+1)x=eʸ−1
x = eʸ − 1eʸ + 1

对任意 y∈ℝ，令 a=eʸ>0，令 z=(a−1)/(a+1)。有

z+1 = 2aa+1 > 0，1−z = 2a+1 > 0

因此 −1<z<1，且 (1+z)/(1−z)=a=eʸ，从而 f(z)=y。这证明原函数值域为 ℝ。按惯例用 x 表示反函数的自变量，得到

f⁻¹(x) = eˣ − 1eˣ + 1，x ∈ ℝ

反函数的值域是原函数的定义域 (−1,1)，端点均不取到。

③ 分别核对原函数与反函数的奇偶性

——————2分

原函数定义域 (−1,1) 关于0对称，且对其中任意 x，

f(−x) = ln 1−x1+x = −ln 1+x1−x = −f(x)

所以 f 为奇函数。反函数 g=f⁻¹ 的定义域 ℝ 也关于0对称。分子、分母同乘正数 eˣ，得

g(−x) = e⁻ˣ − 1e⁻ˣ + 1 = 1−eˣ1+eˣ = −g(x)

所以反函数也是奇函数。两者均非零函数，故并非偶函数。

最终结果

值域为 ℝ；两者均为奇函数。

f⁻¹(x) = eˣ − 1eˣ + 1

这里的分值仅为教学建议，不是原题分值；实际考试以老师的评分标准为准。

04

易错提醒

反解得到表达式，就直接宣布值域是 ℝ⌄

反解式有意义还不够，必须验证它给出的输入在原函数定义域内，并且代回能得到对应输出。本题用 −1<(eʸ−1)/(eʸ+1)<1 和代回检验补齐了这一步。

把 f⁻¹(x) 当成 1/f(x)⌄

f⁻¹ 表示反函数，即把函数的输入与输出对应关系反过来，不是原函数的倒数。此题反函数的定义域是 ℝ，而不是照抄原函数的 (−1,1)。

只看 f(−x)=−f(x)，漏掉定义域对称⌄

奇函数要求定义域关于0对称，并在域内处处满足 f(−x)=−f(x)。例如将同一个奇函数表达式仅限制在 (0,1) 上，就不能再把这个受限函数称为奇函数。

把对数的真数取负与取倒数混淆⌄

这里用的是 ln(1/a)=−ln a，要求 a>0；不是 ln(−a)=−ln a。原定义域保证 (1+x)/(1−x)>0，因此取倒数与对数运算合法。
