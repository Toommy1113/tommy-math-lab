用极限定义证明

概念
01 读题与识别 / 第03题 · 用定义证明第一章方法可解

用 ε–δ 定义证明：

limx → 1x² = 1
知识点
02

拆解思路

1

题目要证明的，是误差能被任意压小

题型判断：ε–δ 定义证明 · 从误差目标倒推邻域。

看到“用 ε–δ 定义证明”，我会先把目标写成不等式：给定任意 ε>0，要找到一个 δ>0，使 0<|x−1|<δ 时必有 |x²−1|<ε。直接代入能猜到极限是1，但没有回答：输入究竟要靠近1到什么程度，才能保证输出误差小于 ε？

所以我的任务是根据 ε 选出 δ。δ 可以依赖 ε，但不能等看到具体 x 后再临时选择。

2

把目标拆成“能控制的距离”和“还在变化的因子”

|x²−1| = |x−1| · |x+1|

|x−1| 正是题目允许我用 δ 控制的距离，但 |x+1| 还随 x 变化。如果直接要求 |x−1|<ε/|x+1|，右边还含 x，就没有给出一个对整段邻域都有效的 δ。

我会先把 x 限制在1附近一个固定范围，例如 |x−1|<1。由三角不等式，|x+1|≤|x−1|+2<3，于是

|x²−1| < 3|x−1|

这一步的作用是用常数3替代变化的 |x+1|。现在只要再让 |x−1|<ε/3，目标误差就能小于 ε。

3

把两个要求合并，再从头检查是否足够

前面用了两个要求：距离要小于1，以保证放缩成立；还要小于 ε/3，以保证误差足够小。所以我会取

δ = min{1, ε/3}

取较小值能让两个条件同时成立。接下来写正式证明时，顺序要反过来：先给定任意 ε>0，再定义 δ，最后对满足 0<|x−1|<δ 的任意 x，证明误差小于 ε。这样才能验证这个 δ 对整个邻域都有效。

δ 不需要最大或唯一，只要正且足够小即可。把 ε 分大小讨论也能完成，但取 min 可以用同一段推理覆盖所有 ε。

优先方法：先放缩，再选 δ，最后正向验证

因式分解显出了可直接控制的 |x−1|，固定邻域又把剩余因子界住，所以我选“先放缩、后取 min”。连续性可以更快得到极限值，却没有完成本题指定的定义证明。找 δ 时可以倒推，交卷时还要正向验证；这条方法适用于能把目标误差估计为常数乘输入距离的情形。

我的解题经验总结

这道题要训练的是为任意输出误差要求，给出统一有效的输入距离。以后做定义证明，我会先写目标误差，尝试显出 |x−a|，再界住其他因子；找到 δ 后，从量词顺序出发把保证关系完整验证一遍。

03完整解答展开步骤⌄
教学总分 6 分

① 任意给定 ε，明确所选 δ

——————2分

任意给定 ε>0，取

δ = min{1, ε/3} > 0

则 δ 仅依赖 ε。以下对任意满足 0<|x−1|<δ 的实数 x 进行验证。

② 关键：利用固定邻域控制剩余因子

——————3分

由于 |x−1|<δ≤1，根据三角不等式，

|x+1| = |(x−1)+2| ≤ |x−1|+2 < 3

再由平方差分解，得到

|x²−1| = |x−1||x+1| < 3|x−1| < 3δ ≤ ε

其中第一次严格不等式使用 0<|x−1| 和 |x+1|<3；第二次使用 |x−1|<δ；最后使用 δ≤ε/3。

③ 回到定义，完成结论

——————1分

因此，对任意 ε>0，均存在上述 δ>0，使得 0<|x−1|<δ 时 |x²−1|<ε。根据函数极限的 ε–δ 定义，

limx → 1 x² = 1
最终结果

可取 δ = min{1, ε/3}。

这里的分值仅为教学建议，不是原题分值；实际考试以老师的评分标准为准。

04

易错提醒

把 δ 写成 ε/|x+1|⌄

这个表达式依赖待检验的 x，没有给出对整个邻域统一有效的 δ。此题先利用固定邻域，把 |x+1| 统一界在3以内，才得到只依赖 ε 的选择。

只取 δ=ε/3，却没有保证 |x+1|<3⌄

放缩 |x+1|<3 用到了 |x−1|<1，不能悄悄省掉。例如 ε=12 时若取 δ=4，x=4 满足 0<|x−1|<δ，但 |x²−1|=15>12。因此要用 min 把固定邻域条件也保留下来。

只写“令 x=1 得到1”，或只列出 δ⌄

代入或连续性结论不能替代题目要求的定义证明。写出 δ 后，还需对邻域内任意 x 验证 |x²−1|<ε，而不是仅检查某一个点。

以为 δ 必须是最精确或最大的范围⌄

定义只要求存在合适的正数 δ。若某个 δ 有效，更小的正数也有效；例如 min{1/2, ε/3} 同样可以。重点是证明其有效，不是追求最大的 δ。
