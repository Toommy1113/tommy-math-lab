由等价关系确定参数

重点
01 读题与识别 / 第10题 · 求极限第一章方法可解

当 x → 0 时，下列两式等价，求 k。

kx² ∼ 1 + x arcsin x − 1
知识点
02

拆解思路

1

“等价”让我先找整个根式差与 x² 的比值

题型判断：等价无穷小确定参数。

题目不是问根式差趋于什么值——它趋于0；而是问哪个 k 能让 kx² 与它的比值趋于1。看到 x arcsin x，我先想起 arcsin x/x→1，所以内层约为 x²。接下来还要确认外层根式差是否仍是二阶。

2

有理化后，内层的 x² 就显出来了

我选择共轭有理化，是因为它把整个 √(1+x arcsin x)−1 变为 x arcsin x 除以一个趋于2的量：

√(1+x arcsin x) − 1 = x arcsin x√(1+x arcsin x) + 1

这样既保留了相减结果，也把 x arcsin x 与目标 x² 对上。只有根式差作为整体完成比较，才能用等价关系；不能在差式内部把根号直接代成1。

3

把比值化到常数，再解 k

√(1+x arcsin x) − 1x² = arcsin x / x√(1+x arcsin x) + 1 → 12

对 0<|x|<1，arcsin x 与 x 同号，根式差不为零，且根号内在0附近为正。若 kx² 与根式差等价，则 kx²/(根式差)→1；由上式反推 k=1/2。这里用弧度制，arcsin x/x→1 可由正弦重要极限得到。

优先方法：有理化后按等价定义比较

我会先有理化，使“等价”问题变为一个明确的比值极限。也可以套 √(1+u)−1∼u/2，但这里写出共轭式能直接核对 u=x arcsin x→0，并避免把相减式逐项替换。适用于根号真数在1附近且增量能与目标幂配上的情况。

我的解题经验总结

本题真正考察的是等价关系所要求的比值，而不是两个式子都趋于零。以后遇到“求参数使两式等价”，我会先找目标量的阶，随后计算整个式子与目标幂的比值，并核对分母在去心邻域中非零。

03完整解答展开步骤⌄
教学总分 6 分

① 确认定义域与等价所需的比值

——————2分

取充分小的 0<|x|<1。arcsin x 有定义，且 x arcsin x>0，所以 1+x arcsin x>0、根式差>0。由于 arcsin x/x→1，有 x arcsin x→0；弧度制下该反三角极限由 sin u/u→1 与局部反函数关系得出。

② 关键：求根式差与 x² 的比值

——————3分
√(1+x arcsin x) − 1x² = x arcsin xx²(√(1+x arcsin x) + 1) = arcsin x / x√(1+x arcsin x) + 1

当 x→0 时，分子趋于1，分母趋于2，故整个比值趋于1/2。恒等变形中分母在所取范围内均非零。

③ 按定义确定参数

——————1分
limx → 0kx²√(1+x arcsin x) − 1 = k · 11/2 = 2k

等价要求上述比值为1，因此 2k=1，k=1/2；此时 kx² 与根式差都为非零无穷小，满足定义。

最终结果k = 12

这里的分值仅为教学建议（条件与识别2分、关键变形3分、求值1分），不是原题分值；实际考试以老师的评分标准为准。

04

易错提醒

只因两式都趋于0，就认为任意 k 都等价⌄

两者同趋零不够；等价要求比值趋于1。例如 k=1 时，该比值趋于2。

把 arcsin x 当成 x² 或漏掉根号的1/2⌄

arcsin x∼x，因而 x arcsin x∼x²；而 √(1+u)−1∼u/2，不能略去外层的系数1/2。

在相减式里逐项代入，把根式差写成0⌄

连续性只能得到差的极限为0，无法读出二阶主项。应对整个差有理化，再与 x² 比较。
