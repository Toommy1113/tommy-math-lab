递推数列的收敛与极限

重点
01 读题与识别 / 第17题 · 证明收敛并求极限第一章方法可解

证明数列收敛，并求极限。

−1 < x₀ < 0，xₙ₊₁ = xₙ² + 2xₙ（n ≥ 0）
知识点
02

拆解思路

1

递推式里有 xₙ²，我先看它会不会把数列推到区间外

题型判断：递推数列的单调有界准则。

题目直接给出 −1

xₙ₊₁+1 = (xₙ+1)²
2

再看相邻两项之差，判断是否朝着下界移动

xₙ₊₁−xₙ = xₙ(xₙ+1) < 0

由于已知 −1我先证明有下界和单调，是为了给“极限存在”一个理由；不能一开始就假设极限存在，再把它代进递推式。单调有界准则现在保证收敛。

3

有了收敛，才对递推等式取极限并排除假根

设 xₙ→A。移位序列 xₙ₊₁ 也趋于 A，所以 A=A²+2A，即 A(A+1)=0；候选是0与−1。递减又给出 xₙ≤x₀<0，因此 A≤x₀<0，0 不可能，最终 A=−1。只列方程会多出0，区间与单调信息正是排除它的依据。

优先方法：先证区间不变和单调，再代入极限

我会先证 (−1,0) 对递推保持不变，再比较 xₙ₊₁−xₙ；这两步足以用单调有界准则证明极限存在。最后用递推方程求候选值，并用 xₙ≤x₀<0 排除0。这条顺序适用于能找到不变区间和固定单调方向的递推题；只有解代数方程不足以证明收敛。

我的解题经验总结

这道题训练的是先证明极限存在，再用方程计算它。以后遇到递推数列，我会先找区间是否保持不变，再算相邻差确定单调性；得到收敛后，才取极限并用初值范围筛选候选值。

03完整解答展开步骤⌄
教学总分 8 分

① 归纳证明 −1——————2分

初值满足 −1

② 关键：证明单调有界，确立极限存在

——————4分
xₙ₊₁−xₙ = (xₙ²+2xₙ)−xₙ = xₙ(xₙ+1)<0

因此 {xₙ} 严格递减，且始终大于−1。由单调有界准则，存在有限极限 A；并由 xₙ≤x₀<0 得 A≤x₀<0。

③ 取极限、解方程并筛选

——————2分

xₙ→A 蕴含 xₙ₊₁→A。由多项式连续性对递推等式两侧取极限：

A = A²+2A ⇒ A(A+1)=0 ⇒ A=0 或 A=−1

又 A≤x₀<0，排除 A=0，因此

limn → ∞xₙ = −1
最终结果limₙ→∞ xₙ = −1

这里的分值仅为教学建议（前提2分、关键步骤4分、结论2分），不是原题分值；实际考试以老师的评分标准为准。

04

易错提醒

先写“令 lim xₙ=A”，却没有证明它存在⌄

把极限代入递推式只能找候选值；此时收敛还未建立。先证区间不变和单调有界，再使用极限运算法则。

解得0和−1，就任选一个或两个都保留⌄

方程的根只是可能极限。因 xₙ≤x₀<0，有限极限 A 不会等于0；必须结合初值和单调性筛选。

仅从 −1⌄

被限制在区间内不意味着一定收敛，更不意味着趋于边界。这里还需要相邻差小于0和单调有界准则。

从 xₙ<0 错推 A<0⌄

每项严格小于0，极限仍可能是0，如 −1/n→0。本题排除0依赖更强的 xₙ≤x₀<0，其中 x₀ 是固定负数。
