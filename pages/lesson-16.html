项数增加的求和极限

重点
01 读题与识别 / 第16题 · 求极限第一章方法可解

利用极限存在准则求极限：

limn → ∞n + 1n² + 1 + n + 2n² + 2 + ⋯ + n + nn² + n
知识点
02

拆解思路

1

先看共有 n 项：每项都小，和却不一定小

题型判断：项数随 n 增加的数列求和 · 夹逼准则。

题目从 k=1 加到 k=n，项数也随着 n 变。我不能只说每一项大约是1/n，于是把总和当成1；分子 n+k 中的 k 从1走到 n，改变了整组项的平均大小。我会先把它写为一个统一的和式，看看哪些部分可以对所有 k 一起控制。

Sₙ = Σ(k=1,…,n) (n+k)/(n²+k)
2

分母变化范围窄，统一放缩能保留分子的总贡献

对 1≤k≤n，分母满足 n²≤n²+k≤n²+n，而分子 n+k>0。因此每一项都能夹在两个共享分母的分数之间：

n+kn²+n ≤ n+kn²+k ≤ n+kn²

我选放缩分母，是因为这样保留了分子随 k 变化的信息，同时把 n 个难求的分数变成两个可以直接求和的式子。下界用较大分母，上界用较小分母，方向不能弄反。

3

算出分子总和，看两侧是否夹到同一个值

Σ(k=1,…,n)(n+k) = n² + n(n+1)/2 = (3n²+n)/2

所以 Sₙ 的下界是 (3n²+n)/[2(n²+n)]，上界是 (3n²+n)/(2n²)。同除 n²，两边都趋于3/2，夹逼得原极限。每项的“近似”不必有对整个求和范围统一的误差证明，因为这里用的是对所有 1≤k≤n 都成立的精确不等式。

优先方法：统一放缩每一项，再求和夹逼

此题要用极限存在准则，分母在 n² 与 n²+n 之间，且各分子为正，统一放缩正好给出两个可求的和。我优先用夹逼；如果逐项固定 k 求极限，就忽略了项数 n 也在增加。适用于每项可被同一组便于求和的上下界控制，且两边极限相同的情况。

我的解题经验总结

这道题真正难的是项数和项值同时变化。以后看到 n 项的和，我会先写通项，找一个对所有 1≤k≤n 都成立的统一估计，再求上下界的和；不能把固定项的极限直接加 n 次。

03完整解答展开步骤⌄
教学总分 6 分

① 写出通项并核对放缩条件

——————2分

记 Sₙ=Σₖ₌₁ⁿ(n+k)/(n²+k)，n≥1。对每个 1≤k≤n，有 n+k>0 且 n²≤n²+k≤n²+n，分母均为正。

② 关键：逐项统一放缩并求和

——————3分
n+kn²+n ≤ n+kn²+k ≤ n+kn²

对 k=1,…,n 求和，不等号方向不变：

Σ(k=1,…,n)(n+k)n²+n ≤ Sₙ ≤ Σ(k=1,…,n)(n+k)n²
Σ(k=1,…,n)(n+k) = n² + n(n+1)2 = 3n²+n2

③ 计算上下界极限并应用夹逼

——————1分
3n²+n2(n²+n) ≤ Sₙ ≤ 3n²+n2n²

上下界分别为 (3+1/n)/[2(1+1/n)] 与 (3+1/n)/2，均趋于3/2。

limn → ∞Sₙ = 32
最终结果32

这里的分值仅为教学建议（前提2分、关键步骤3分、结论1分），不是原题分值；实际考试以老师的评分标准为准。

04

易错提醒

把每项的固定 k 极限直接求和 n 次⌄

求和项数随 n 增长，不属于固定有限项和的极限法则。即使每项趋于0，也不能因此认为和趋于0；n 项 1/n 的和恒为1。

把 n+k 全部替换成 n⌄

当 k 接近 n 时，n+k 接近2n，差与 n 同阶；把每项分子都改成 n 会丢掉 k 的总贡献 n(n+1)/2。

放缩分母时把不等号写反⌄

分子 n+k>0：分母越大，分数越小。因此 n²+n 对应下界，n² 对应上界。

只证明 Sₙ 有界就断言它趋于3/2⌄

有界只能约束范围，不足以确定极限。本题是上下界都趋于同一个 3/2，才能由夹逼得出结论。
